# AI Test Generator

Автоматический генератор unit-тестов для Python и JavaScript с использованием LLM. Создает тесты, покрывающие happy path, edge cases и обработку ошибок.

## Возможности

- Автоматическое извлечение функций из кода с помощью AST (Python) и regex (JavaScript)
- Генерация тестов для pytest (Python) и Jest (JavaScript)
- Покрытие нормальных случаев, граничных случаев и обработки ошибок
- Валидация синтаксиса сгенерированных тестов
- Параметризованные тесты где уместно
- Описательные имена тестов и docstrings

## Установка

1. Клонируйте репозиторий или скопируйте файлы

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Установите переменную окружения с API ключом:
```bash
# Linux/Mac
export GEMINI_API_KEY=your_api_key_here

# Windows (PowerShell)
$env:GEMINI_API_KEY="your_api_key_here"

# Windows (CMD)
set GEMINI_API_KEY=your_api_key_here
```

1. Перейдите на https://aistudio.google.com
2. Войдите с помощью Google аккаунта
3. Нажмите "Get API Key"
4. Создайте новый ключ и скопируйте его

## Использование

### Базовое использование

```bash
# Генерация тестов для Python файла
python test-generator.py calculator.py
```

### Указание директории для тестов

```bash
# Сохранить тесты в директорию tests/
python test-generator.py calculator.py -o tests/

# Сохранить в текущую директорию
python test-generator.py calculator.py -o .
```

### Генерация тестов для конкретной функции

```bash
# Только для функции add
python test-generator.py calculator.py --function add

# Сокращенная форма
python test-generator.py calculator.py -f add
```

### Валидация синтаксиса

```bash
# Проверить синтаксис сгенерированных тестов
python test-generator.py calculator.py --validate

# Сокращенная форма
python test-generator.py calculator.py -v
```

### Режим dry-run

```bash
# Показать тесты без сохранения
python test-generator.py calculator.py --dry-run

# Сокращенная форма
python test-generator.py calculator.py -d
```

## Примеры

### Python

Исходный файл `calculator.py`:
```python
def add(a: int, b: int) -> int:
    """Складывает два числа."""
    return a + b

def divide(a: float, b: float) -> float:
    """Делит a на b."""
    if b == 0:
        raise ValueError("Division by zero")
    return a / b
```

Команда:
```bash
python test-generator.py calculator.py
```

Сгенерированный файл `test_calculator.py`:
```python
"""
Unit tests for calculator.py
Generated by AI Test Generator
"""

import pytest
from calculator import add, divide

# Tests for add
def test_add_positive_numbers():
    """Test adding two positive numbers."""
    assert add(2, 3) == 5

def test_add_negative_numbers():
    """Test adding two negative numbers."""
    assert add(-2, -3) == -5

def test_add_zero():
    """Test adding zero."""
    assert add(5, 0) == 5
    assert add(0, 5) == 5

# Tests for divide
def test_divide_positive_numbers():
    """Test dividing two positive numbers."""
    assert divide(10, 2) == 5.0

def test_divide_by_zero_raises_error():
    """Test that dividing by zero raises ValueError."""
    with pytest.raises(ValueError, match="Division by zero"):
        divide(10, 0)

def test_divide_negative_numbers():
    """Test dividing negative numbers."""
    assert divide(-10, 2) == -5.0
```

### JavaScript

Исходный файл `utils.js`:
```javascript
function validateEmail(email) {
    const regex = /^[^\s@]+@[^\s@]+\.[^\s@]+$/;
    return regex.test(email);
}

export function formatPrice(price) {
    if (typeof price !== 'number') {
        throw new TypeError('Price must be a number');
    }
    return `$${price.toFixed(2)}`;
}
```

Команда:
```bash
python test-generator.py utils.js
```

Сгенерированный файл `utils.test.js`:
```javascript
/**
 * Unit tests for utils.js
 * Generated by AI Test Generator
 */

import { validateEmail, formatPrice } from './utils';

describe('validateEmail', () => {
    test('validates correct email', () => {
        expect(validateEmail('test@example.com')).toBe(true);
    });

    test('rejects email without @', () => {
        expect(validateEmail('testexample.com')).toBe(false);
    });

    test('rejects empty string', () => {
        expect(validateEmail('')).toBe(false);
    });
});

describe('formatPrice', () => {
    test('formats price correctly', () => {
        expect(formatPrice(10.5)).toBe('$10.50');
    });

    test('throws error for non-number', () => {
        expect(() => formatPrice('10')).toThrow(TypeError);
    });

    test('handles zero', () => {
        expect(formatPrice(0)).toBe('$0.00');
    });
});
```

## Поддерживаемые языки и фреймворки

### Python
- **Расширения**: `.py`
- **Тестовый фреймворк**: pytest
- **Извлечение функций**: AST (Abstract Syntax Tree)
- **Формат файла тестов**: `test_<filename>.py`

### JavaScript
- **Расширения**: `.js`, `.mjs`, `.cjs`
- **Тестовый фреймворк**: Jest
- **Извлечение функций**: Regex
- **Формат файла тестов**: `<filename>.test.js`

## Что покрывают тесты

1. **Happy Path**: Нормальные случаи использования с корректными данными
2. **Edge Cases**: Граничные значения, пустые значения, null/undefined/None
3. **Error Handling**: Проверка выброса исключений и обработки ошибок
4. **Параметризация**: Использование pytest.mark.parametrize для множественных входных данных

## Технические детали

- **Язык**: Python 3.8+
- **LLM**: Google Gemini 2.5 Flash
- **AST парсинг**: встроенный модуль ast для Python
- **Валидация**: проверка синтаксиса через ast.parse()

## Запуск сгенерированных тестов

### Python (pytest)
```bash
# Установить pytest если еще не установлен
pip install pytest

# Запустить тесты для calculator.py
pytest test_calculator.py

# С подробным выводом
pytest test_calculator.py -v

# С покрытием кода
pytest test_calculator.py --cov=calculator
```

### JavaScript (Jest)
```bash
# Установить Jest если еще не установлен
npm install --save-dev jest

# Запустить тесты для utils.js
npm test utils.test.js

# Или напрямую через jest
npx jest utils.test.js
```

## Ограничения

- Извлечение JavaScript функций использует regex (может пропустить сложные случаи)
- Приватные функции (начинающиеся с `_`) пропускаются
- Методы классов в Python могут требовать дополнительной настройки
- Google AI Studio (Gemini): ~20 запросов/день (бесплатный tier)

## Рекомендации

1. Проверяйте сгенерированные тесты перед использованием
2. Используйте `--validate` для проверки синтаксиса
3. Дополняйте тесты специфичными для вашего проекта случаями
4. Запускайте тесты для проверки их корректности
5. Используйте `--function` для итеративной генерации тестов
