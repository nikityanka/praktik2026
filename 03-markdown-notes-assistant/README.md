# Markdown Notes Assistant

Инструмент для анализа связей между markdown-заметками с использованием embeddings и AI. Идеально подходит для Obsidian, Notion и других систем управления знаниями.

## Возможности

- Рекурсивное сканирование папки с .md файлами
- Поиск смысловых связей между заметками с помощью embeddings
- Вычисление косинусной близости для определения похожих заметок
- Генерация кратких summary для каждой заметки
- Автоматическое добавление summary в frontmatter
- Безопасная работа с пользовательскими файлами (требует подтверждения)

## Установка

1. Клонируйте репозиторий или скопируйте файлы

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Установите переменную окружения с API ключом:
```bash
# Linux/Mac
export GEMINI_API_KEY=your_api_key_here

# Windows (PowerShell)
$env:GEMINI_API_KEY="your_api_key_here"

# Windows (CMD)
set GEMINI_API_KEY=your_api_key_here
```

## Получение API ключа

1. Перейдите на https://aistudio.google.com
2. Войдите с помощью Google аккаунта
3. Нажмите "Get API Key"
4. Создайте новый ключ и скопируйте его

## Использование

### Базовое использование

```bash
# Анализ связей между заметками в текущей директории
python notes-assistant.py .

# Анализ конкретной папки
python notes-assistant.py C:\Users\Nikita\Desktop\pp\03-markdown-notes-assistant
```

### Настройка порога схожести

```bash
# Более строгий порог (только очень похожие заметки)
python notes-assistant.py . --threshold 0.8

# Более мягкий порог (больше предложений)
python notes-assistant.py . --threshold 0.6
```

### Генерация summaries

```bash
# Генерировать summary для каждой заметки и добавить в frontmatter
python notes-assistant.py . --generate-summaries

# Сокращенная форма
python notes-assistant.py . -s
```

### Ограничение количества предложений

```bash
# Показать только топ-5 связей
python notes-assistant.py . --max-suggestions 5

# Показать все найденные связи
python notes-assistant.py . --max-suggestions 1000
```

### Автоматическое обновление (без подтверждения)

```bash
# ОСТОРОЖНО: автоматически обновляет файлы
python notes-assistant.py . -s --auto-update
```

## Формат frontmatter

Инструмент добавляет summary в YAML frontmatter:

```markdown
---
summary: Краткое описание основной идеи заметки в 1-2 предложениях
---

# Заголовок заметки

Содержимое заметки...
```

## Флаги командной строки

```
directory                Путь к папке с markdown заметками (обязательный)
--threshold, -t          Порог схожести (0.0-1.0, по умолчанию: 0.7)
--generate-summaries, -s Генерировать summary для каждой заметки
--auto-update            Автоматически обновлять файлы без подтверждения
--max-suggestions        Максимальное количество предложений (по умолчанию: 10)
--help, -h               Показать справку
```

## Технические детали

- **Язык**: Python 3.8+
- **Embeddings**: Google Gemini embedding-001
- **Метрика схожести**: Косинусная близость
- **LLM для summaries**: Google Gemini 2.5 Flash
- **Максимальная длина текста для embedding**: 10000 символов

## Как это работает

1. **Сканирование**: Рекурсивно находит все .md файлы в указанной директории
2. **Парсинг**: Читает содержимое, извлекает frontmatter и основной текст
3. **Очистка**: Удаляет markdown-разметку для получения чистого текста
4. **Embeddings**: Создает векторные представления для каждой заметки
5. **Сравнение**: Вычисляет косинусную близость между всеми парами заметок
6. **Фильтрация**: Отбирает пары с схожестью выше порога
7. **Вывод**: Показывает результаты, отсортированные по убыванию схожести

## Интеграция с Obsidian

После получения предложений о связях, вы можете:

1. Открыть заметки в Obsidian
2. Добавить ссылки вручную в формате `[[Название заметки]]`
3. Использовать граф связей Obsidian для визуализации

Пример добавления ссылки:
```markdown
Эта концепция связана с [[Machine Learning Basics]] и [[Neural Networks]].
```

## Рекомендации по использованию

- **Порог 0.7-0.8**: Оптимальный баланс между точностью и полнотой
- **Порог 0.6-0.7**: Больше предложений, но могут быть ложные срабатывания
- **Порог 0.8-0.9**: Только очень похожие заметки, может указывать на дублирование
- **Порог 0.9+**: Практически идентичные заметки

## Ограничения

- Google AI Studio (Gemini): ~1500 запросов/день
- Embeddings API: ограничение на длину текста (10000 символов)
- Обработка большого количества заметок может занять время
- Требуется интернет-соединение для работы с API

## Безопасность

- Инструмент запрашивает подтверждение перед изменением файлов
- Используйте `--auto-update` только если уверены в результатах
- Рекомендуется сделать резервную копию заметок перед первым запуском
- Инструмент не удаляет и не перезаписывает существующий контент
