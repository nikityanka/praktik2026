# Voice to Task

Конвертирует голосовые заметки в структурированные задачи. Использует AI для транскрипции аудио и преобразования в задачи с заголовком, описанием, приоритетом, тегами и дедлайном.

## Возможности

- Транскрипция голосовых заметок с помощью Gemini API
- Автоматическое извлечение структуры задачи
- Определение приоритета на основе контекста
- Извлечение дедлайнов из естественного языка
- Генерация списка действий (action items)
- Автоматическое создание тегов
- Экспорт в text, markdown, JSON
- Поддержка множества аудио форматов

## Установка

1. Клонируйте репозиторий или скопируйте файлы

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Создайте файл `.env` на основе `.env.example`:
```bash
# Linux/Mac
cp .env.example .env

# Windows (PowerShell)
Copy-Item .env.example .env

# Windows (CMD)
copy .env.example .env
```

4. Откройте `.env` и добавьте ваш API ключ:
```
GEMINI_API_KEY=your_api_key_here
```

Альтернативно, можно установить переменную окружения:
```bash
# Linux/Mac
export GEMINI_API_KEY=your_api_key_here

# Windows (PowerShell)
$env:GEMINI_API_KEY="your_api_key_here"

# Windows (CMD)
set GEMINI_API_KEY=your_api_key_here
```

## Получение API ключа

1. Перейдите на https://aistudio.google.com
2. Войдите с помощью Google аккаунта
3. Нажмите "Get API Key"
4. Создайте новый ключ и скопируйте его

## Использование

### Базовое использование

```bash
# Конвертировать голосовую заметку в задачу
python voice-to-task.py voice.mp3

# С указанием формата вывода
python voice-to-task.py voice.mp3 --format markdown

# Сохранить в файл
python voice-to-task.py voice.mp3 --format json --output task.json
```

### Только транскрипция

```bash
# Получить только текст транскрипции
python voice-to-task.py voice.mp3 --transcription-only

# Сохранить транскрипцию в файл
python voice-to-task.py voice.mp3 -t -o transcription.txt
```

### Показать транскрипцию

```bash
# Показать транскрипцию перед структурированной задачей
python voice-to-task.py voice.mp3 --show-transcription
```

## Структура задачи

Каждая задача содержит следующие поля:

- **title**: Краткий заголовок (до 50 символов)
- **description**: Подробное описание задачи
- **priority**: Приоритет (high/medium/low)
- **tags**: Массив релевантных тегов
- **deadline**: Дедлайн в формате YYYY-MM-DD (или null)
- **estimated_time**: Оценка времени в часах (или null)
- **action_items**: Список конкретных действий
- **context**: Дополнительный контекст или заметки

## Определение приоритета

Система автоматически определяет приоритет на основе:

- **High**: Слова "срочно", "критично", "важно", "немедленно", короткие дедлайны
- **Medium**: Обычные задачи с умеренными сроками
- **Low**: Задачи без срочности, долгосрочные планы

## Извлечение дедлайнов

Система понимает естественный язык:

- "завтра" → следующий день
- "послезавтра" → через 2 дня
- "на следующей неделе" → следующий понедельник
- "до пятницы" → ближайшая пятница
- "через неделю" → +7 дней
- "в конце месяца" → последний день месяца

## Поддерживаемые форматы аудио

- `.mp3` - MP3
- `.wav` - WAV
- `.m4a` - M4A/AAC
- `.ogg` - Ogg Vorbis
- `.flac` - FLAC

## Флаги командной строки

```
audio                     Путь к аудио файлу (обязательный)
--format, -f              Формат вывода: text, markdown, json
--output, -o              Сохранить результат в файл
--transcription-only, -t  Только транскрибировать без структурирования
--show-transcription      Показать транскрипцию перед задачей
--help, -h                Показать справку
```

## Технические детали

- **Транскрипция**: Google Gemini 2.5 Flash (с поддержкой аудио)
- **Структурирование**: Google Gemini 2.5 Flash
- **Максимальная длина аудио**: Зависит от API (обычно до 25MB)
- **Время обработки**: 10-30 секунд в зависимости от длины аудио

## Интеграция с системами управления задачами

### Todoist

```bash
# Создать задачу в JSON формате
python voice-to-task.py voice.mp3 --format json --output task.json

# Импортировать в Todoist через API
curl "https://api.todoist.com/rest/v2/tasks" \
  -X POST \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d @task.json
```

### Notion

```python
import json
from notion_client import Client

# Конвертировать голосовую заметку
# python voice-to-task.py voice.mp3 --format json --output task.json

# Загрузить в Notion
notion = Client(auth="YOUR_NOTION_TOKEN")
with open('task.json') as f:
    task = json.load(f)

notion.pages.create(
    parent={"database_id": "YOUR_DATABASE_ID"},
    properties={
        "Name": {"title": [{"text": {"content": task['title']}}]},
        "Priority": {"select": {"name": task['priority']}},
        "Due Date": {"date": {"start": task['deadline']}},
        "Tags": {"multi_select": [{"name": tag} for tag in task['tags']]}
    }
)
```

## Рекомендации

### Для лучших результатов

1. **Четкая речь**: Говорите разборчиво и не слишком быстро
2. **Структура**: Упоминайте ключевые элементы (что, когда, зачем)
3. **Контекст**: Добавляйте важные детали и приоритет
4. **Дедлайны**: Явно указывайте сроки
5. **Действия**: Перечисляйте конкретные шаги

### Примеры хороших голосовых заметок

✓ "Нужно срочно исправить баг с оплатой до завтра. Проверить интеграцию с платежным шлюзом, найти ошибку, протестировать и задеплоить."

✓ "На следующей неделе написать статью о новых фичах. Включить скриншоты, примеры кода и инструкции. Примерно 4 часа работы."

✓ "Созвониться с клиентом в пятницу для обсуждения требований к проекту. Подготовить вопросы заранее."

### Примеры плохих голосовых заметок

✗ "Что-то сделать" (слишком неконкретно)

✗ "Ммм... ну... типа... надо бы..." (много слов-паразитов)

✗ Очень длинная заметка без структуры (лучше разбить на несколько)

## Ограничения

- Google AI Studio (Gemini): ~1500 запросов/день
- Качество транскрипции зависит от качества аудио
- Лучше работает с четкой речью
- Фоновый шум может ухудшить результат
- Максимальная длина аудио ограничена API

## Устранение неполадок

### Плохая транскрипция

- Проверьте качество записи
- Уменьшите фоновый шум
- Говорите четче и медленнее
- Используйте хороший микрофон

### Неправильная структура задачи

- Добавьте больше контекста в голосовую заметку
- Явно указывайте приоритет и дедлайн
- Перечисляйте конкретные действия

### Ошибка при обработке

- Проверьте формат аудио файла
- Убедитесь, что файл не поврежден
- Проверьте размер файла (не более 25MB)
