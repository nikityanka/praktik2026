# Telegram Article Summarizer Bot

Telegram-бот для создания кратких содержаний статей с использованием Google Gemini API.

## Возможности

- Извлечение текста из веб-статей
- Создание краткого содержания в 5 пунктах
- Обработка длинных статей с чанкингом
- Обработка ошибок (битые ссылки, пейволы, таймауты)

## Установка

1. Клонируйте репозиторий или скопируйте файлы

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Создайте файл `.env` и добавьте ваши API ключи:
```
TELEGRAM_BOT_TOKEN=your_telegram_bot_token_here
GEMINI_API_KEY=your_gemini_api_key_here
```

## Получение API ключей

### Telegram Bot Token
1. Откройте Telegram и найдите @BotFather
2. Отправьте команду `/newbot`
3. Следуйте инструкциям для создания бота
4. Скопируйте полученный токен

### Gemini API Key
1. Перейдите на https://aistudio.google.com
2. Войдите с помощью Google аккаунта
3. Нажмите "Get API Key"
4. Создайте новый ключ и скопируйте его

## Запуск

```bash
python bot.py
```

## Использование

1. Найдите вашего бота в Telegram
2. Отправьте команду `/start`
3. Отправьте ссылку на статью
4. Получите краткое содержание в 5 пунктах

## Команды

- `/start` - Начать работу с ботом
- `/help` - Показать справку

## Технические детали

- **Язык**: Python 3.8+
- **Telegram API**: python-telegram-bot 21.0
- **LLM**: Google Gemini 2.5 Flash
- **Извлечение текста**: readability-lxml + BeautifulSoup4
- **Обработка длинных текстов**: автоматический чанкинг с максимальным размером 30000 символов

## Обработка ошибок

Бот обрабатывает следующие ситуации:
- Таймауты при загрузке страниц (10 секунд)
- Битые или недоступные ссылки
- Сайты с пейволами или требующие авторизацию
- Слишком короткие тексты (менее 100 символов)
- Слишком длинные тексты (автоматическое разбиение на части)

## Ограничения

- Google AI Studio (Gemini): ~1500 запросов/день
- Контекст: до 1M токенов
- Некоторые сайты могут блокировать парсинг
